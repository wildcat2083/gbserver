How to play

Controls

  • D-pad, A, B, Start, Select - tap on screen, or use a keyboard/gamepad below
  • Keyboard: Arrow keys, Z/A = A, X/B = B, Enter/W = Start, Shift/Q = Select
  • Gamepad: face buttons and d-pad map automatically once connected over Bluetooth/USB
  • Gamepad: press Y / Triangle to open or close this settings menu, then use the D-pad, A, and B to navigate it - the D-pad drives real game input again once the menu is closed
  • Gamepad: hold X / Square for rapid-fire A - repeatedly presses and releases A on its own while held, for games that need many quick taps in a row

Fast forward

  • Toggle button above the D-pad, or press F1 on a keyboard
  • On a gamepad: RB / R1
  • Audio is muted while fast-forwarding - this is expected, not a bug

Reset

  • Restarts the current ROM completely fresh, like pressing reset on real hardware
  • Press the Reset button, or the * key on a keyboard (same as BGB)
  • On a gamepad: LB / L1
  • Doesn't touch your save file - only in-progress play since the ROM was last loaded is lost

Being in control

  • Whoever connects first becomes the controller - everyone else is a viewer
  • If the controller disconnects, the next person who joined automatically takes over
  • Viewers can still watch, chat, and use fullscreen - just not send button input

Saving

  • The game autosaves in the background every few minutes
  • "Save now" (in Settings) saves immediately, on demand
  • "Play selected" always starts a ROM fresh - "Resume save" explicitly loads its existing save instead
  • Stopping the game also saves automatically before it closes
  • Click "Stop emulation" before closing the browser tab, so that save actually happens

Other things worth knowing

  • Double-click the screen to go fullscreen
  • Private rooms (in Settings) give you a separate game and chat, on their own link, that only people you share it with can join
  • An idle private room is cleared out automatically after a while - the shared game stays around, but stops itself if everyone leaves
  • Old habits die hard - try a classic cheat-code sequence on the D-pad and face buttons sometime
